Hi, I'm Hossam! 👋

I'm a software engineer at [Vodafone EG](https://vodafone.com.eg), and currently, I'm building a drag-and-drop workflow builder. If you have ever spent hours writing the exact same boilerplate code for database queries, HTTP calls, message queues, and cache configurations, you will know exactly why I'm excited about this. We're trying to save workflow developers from that repetitive backend plumbing so they can focus on what actually matters. 

My toolbox mostly revolves around Java, Spring Boot, React, Docker, Git, Keycloak, Linux, and integration platforms like WSO2.

### How I got here

My obsession with coding and cybersecurity started when I was 14. I started messing around with Visual Basic, which felt like magic at the time, and that quickly dragged me down the rabbit hole of Python and Java.

During my early college days, I worked as a low-code developer at [FlowTechHouse](https://www.flowtechouse.com), using Zoho Deluge. I built everything from payroll systems to sales automation and ticketing apps for clients. It was a great crash course in business logic and low-code abstraction, and in a way, it directly shaped how I think about the workflow engines I build today.

After that, I joined [Edafa Telecom Solution](https://www.edafa.com), where I worked on building a loyalty platform for a major telecom operator in Egypt. That's where I spent my days dealing with Spring Boot, Docker, Keycloak, and enterprise integration tools like WSO2 API Manager and WSO2 Streaming Integrator.

Alongside my full-time roles, I've also taken on freelance projects. One highlight was building the backend for a B2B SaaS operations platform for Reef Bread Egypt. I designed and implemented features for invoice management, order tracking, sales visit planning, role-based access control, identity management, and reporting dashboards—all running on Java, Spring Boot, Linux, and Docker.

### What is this blog?

I started this blog to share the things I learn along the way. Expect technical write-ups, architecture notes, and lessons I've learned the hard way throughout my journey.
